# 🐍 Exercices Python — ETNA

Exercices d'apprentissage réalisés dans le cadre de ma formation à l'**ETNA**. Chaque exercice est dans son propre dossier avec son script Python.

## Contenu
| Semaine | Jour | Thèmes |
|---|---|---|
| 2 | 1 | Bases : variables, types, conversions, opérations, formatage de chaînes |
| 2 | 2 | Conditions et boucles : tests, tables de multiplication, nombres premiers, factorielle |
| 2 | 3 | Fonctions, récursivité (factorielle, Fibonacci), listes et chaînes |
| 2 | 4 | Listes, tuples, compréhensions de listes |
| 2 | 5 | Dictionnaires et ensembles |
| 2 | 6 | Fonctions avancées : lambda, `map`/`filter`/`reduce`, closures, décorateurs, `*args`/`**kwargs` |
| 3 | 1 | Manipulation de collections, lecture/écriture de fichiers, gestion des erreurs |
| 3 | 2 | Mini-projet de caisse : panier, ticket, remises, TVA, stock, reçus JSON |
| 3 | 3 | Programmation orientée objet : classes, héritage, inventaire, combats (mini-RPG) |
| 3 | 4 | POO avancée, `property`, sauvegarde et import/export JSON et CSV |

## Structure
```
semaine 2 python/jour_N/NN-nom_de_l_exercice/
semaine 3 python/jour_N/NN-nom_de_l_exercice/
```

## Lancer un exercice
```bash
python3 "semaine 2 python/jour_3/01-fonction_simple/<script>.py"
```

> Mes projets personnels sont dans des dépôts dédiés : [breakout-pygame](https://github.com/auroreskowronski-rgb/breakout-pygame) et [quizify](https://github.com/auroreskowronski-rgb/quizify).
